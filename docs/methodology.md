# 测量方法、来源与限制

## 可重算的数据

`data/provenance.json` 登记原始记录名、原始字节 SHA、公开时的字段选择和源码指纹。源账本、私密对话、生产配置和网络信息留在私有证据库中。

公开文件保留所需的聚合数值、逐次时间及原生统计行。SHA 提供来源身份校验，公开材料自身的可信度仍由保留的可检查数值和实验条件支持。

运行 `python examples/verify_results.py` 可以重算工位两臂中位数、A6000 五臂表格、让行与小块取舍、分段统计等式，并核对归档计数器指纹。

## 分开记录关键路径

每轮观察应包含输入与实际输出 tokens、前缀复用、新读量、prefill、首思考、首正文、decode、总时长、排队与恢复。引擎本机计时、客户端计时和界面等待各有测量边界。

首字字段在早期实验中有不同定义。工位表保留 `cold_first_output_seconds` 的原记录含义；A6000 表明确区分思考和正文。512 输出限额用完时，首正文仍可能是 null。

## 比较条件

- 固定模型权重、量化、输入、思考设置及输出条件，并记录全部改动。
- 同一段历史内的热续接、切换后恢复和真正历史裁剪分别测量。
- 多路使用独立历史，记录实际 active 槽和持续补位。
- 真实 file blob reads 与操作系统文件页缓存需要一起解释。未经控制的文件缓存状态标注为未知。
- 采样最小空余内存只约束观察时刻。容量边界还受瞬时峰值、提交额度和接纳水位影响。
- 保留失败、取消、机制未激活、首次构建错误与后续修正。
